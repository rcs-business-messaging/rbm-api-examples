# RCS Business Messaging: Wallet Integration

This project demonstrates how to integrate Google Wallet and Apple Wallet with
RCS Business Messaging (RBM) using the RBM Python SDK. It acts as an RBM agent
that uses a webhook to receive user messages and send responses with a Rich
Card containing "Save to Wallet" functionality.

## Prerequisites

You must have the following software installed on your development machine:

* [Python][python] - version 3 or above
* [Google Cloud SDK (gcloud)][gcloud]

## Pre-generated Wallet Passes

To make this project run out-of-the-box without requiring you to set up your
own Google Wallet Issuer profile or Apple Developer certificates, it includes
pre-generated pass links and files created via
[WalletWallet](https://walletwallet.alen.ro/).

*   **Google Wallet:** The codebase contains a hardcoded fallback Google Pay
    URL generated by WalletWallet. When a user taps "Save to Wallet" on
    Android, they are seamlessly redirected to this URL.
*   **Apple Wallet:** A `.pkpass` file generated by WalletWallet is included in
    `resources/event_entrance.pkpass` and is served directly to iOS users.

## Setting up the Agent

1.  Open the [RBM Developer Console][rbm-console] with your RBM Platform Google
    account.
2.  Navigate to your partner account settings, find the **Service account**
    section, and click **Create key**. (Keys are managed at the partner level,
    not per-agent). If a key already exists, then you'll need to find the
    service account JSON key file that was created for your partner account
    and use it.
3.  Create a new file at `resources/rbm-service-account.json` and paste the
    contents of your downloaded service account key into it (create the
    `resources/` folder if it doesn't already exist).
4.  Create a new RBM agent in the console. Once created, copy the agent ID.
5.  Create a `.env` file by copying `.env.example`.
6.  Update your `.env` file with the following variable:
    *   `AGENT_ID=[YOUR_AGENT_ID]` (The ID you copied from the RBM console)
7.  Invite your RBM-enabled test phone to the agent by running the included
    CLI tool:
    ```bash
    python register_tester.py +1234567890
    ```
8.  Accept the invite on your device.

## Deploying to Google Cloud Platform (GCP)

To receive messages from users, you need to expose this application via a
public URL. The easiest way is to deploy it to GCP App Engine.

1.  Ensure your `gcloud` CLI is initialized and authenticated:
    ```bash
    gcloud init
    gcloud auth application-default login
    ```
2.  Create a GCP project if you don't have one and set your project ID:
    ```bash
    PROJECT_ID="[YOUR_PROJECT_ID]"
    gcloud config set project $PROJECT_ID
    ```
3.  Initialize the App Engine application within your project (you will be
    prompted to choose a region):
    ```bash
    gcloud app create --project=$PROJECT_ID
    ```
4.  **Configure required IAM Policies:** For the deployment to succeed, you must
    ensure the App Engine and Cloud Build service accounts have proper
    permissions. Run these commands:

    ```bash
    # Grant Editor access to the App Engine default service account
    gcloud projects add-iam-policy-binding $PROJECT_ID \
      --member="serviceAccount:${PROJECT_ID}@appspot.gserviceaccount.com" \
      --role="roles/editor"

    # Grant Artifact Registry Admin access to the Cloud Build service account
    PROJECT_NUM=$(gcloud projects describe $PROJECT_ID \
      --format="value(projectNumber)")
    
    gcloud projects add-iam-policy-binding $PROJECT_ID \
      --member="serviceAccount:${PROJECT_NUM}@cloudbuild.gserviceaccount.com" \
      --role="roles/artifactregistry.repoAdmin"
    ```
5.  Deploy the application to App Engine using the provided script. Your `.env`
    file will be securely uploaded with your app so it can read your Agent ID:
    ```bash
    ./deploy.sh $PROJECT_ID
    ```
6.  Once deployed, note down the URL of your App Engine application (e.g.,
    `https://[YOUR_PROJECT_ID].ue.r.appspot.com`).

## Configuring the RBM Webhook

1.  Go back to your agent in the [RBM Developer Console][rbm-console].
2.  Navigate to the **Integrations** or **Webhook** section.
3.  Enter your deployed App Engine URL with the webhook endpoint (e.g.,
    `https://[YOUR_PROJECT_ID].appspot.com/callback`) as the web hook URL.
4.  Set the **Client Token** to a secure secret string of your choice.
5.  In your application's settings, ensure the same client token is configured
    so your app can verify incoming requests from Google.
6.  Click **Verify** in the RBM Console to finalize the connection.

## Executing Locally

If you wish to test locally before deploying:

1.  Create a virtual environment and install dependencies:
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    ```
2.  Run the application:
    ```bash
    python main.py
    ```
    *(Note: To test the webhook locally, you will need a tool like
    [ngrok][ngrok] to expose your local port to the internet, and then update
    the RBM console with the ngrok URL).*
